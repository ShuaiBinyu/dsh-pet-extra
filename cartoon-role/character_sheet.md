## 二、核心设定

**灵感原型**：以深蓝海洋小鲸鱼为灵感，轻度拟人化设计，保留小鲸鱼圆润头部、鲸鳍与鲸尾等识别特征，形成干净原创的萌系形象。

### 与既有角色明确区分的声明

- 非「鲸鱼娘」变体；
- 不采用女仆系造型；
- 不使用雷姆等既有版权角色的发色、头饰、服装与五官特征；
- 避免任何与原作角色的混淆或衍生关系。

### 明确去除的元素

- 长发；
- 女仆装；
- 雷姆式发色与头饰；
- 暴露或擦边造型；
- 复杂累赘服装。

## 三、外观特征

| 部位 | 设定 |
| --- | --- |
| 体型 | Q版二头身萌宠小萝莉，圆润可爱，桌面宠物感 |
| 头部 | 大而圆，蓝白渐变短发，层次丰富、发尾圆润，刘海分区、两侧小发片 |
| 脸部 | 圆润自然脸型，大而圆的眼睛，简洁可爱、对称的五官 |
| 服装 | 原创洛丽塔连衣裙，小立领、泡泡袖、蝴蝶结、细蕾丝；裙摆超过膝盖至小腿中段，多层荷叶边，不拖地、不遮挡脚底 |
| 标志部位 | 头顶与背部小鲸鳍，身后小鲸尾 |
| 发饰 | 原创海洋感小发饰（水滴 / 贝壳造型） |
| 性别表达 | 中性可爱为主，不做过度女性化设定 |

## 六、创作与保存建议（证据链）

### （一）豆包对话记录保存

豆包平台本身不出具版权证明，对话记录仅为创作过程证据。应将全部迭代对话复制保存为本地 Markdown / TXT 文件，并在本地硬盘与网盘双备份，不可仅依赖云端会话。

### （二）本地文件归档结构

建议建立 `character_whiloco/` 文件夹：

```
character_whiloco/
├── final_ref.png            # 最终参考图
├── character_sheet.md       # 角色设定卡（本文档）
├── dev_log.md               # 创作迭代日志
├── history/                 # 历史迭代草图
└── hash.txt                 # 全部文件 SHA-256 校验值
```

### （三）第三方存证建议

可将定稿角色图与设定文档上传至联合信任时间戳、蚂蚁链存证等正规区块链存证平台，绑定权威时间戳，固定创作完成时间。此类存证证明力度高于普通聊天截图。

### （四）GitHub 提交建议

将角色设定文档、定稿图、迭代日志一并提交至开源仓库，GitHub 的提交记录与提交哈希可作低成本时间证据。建议同时保留区块链时间戳凭证，形成双保险。

### （五）免责提醒

版权自创作完成时即已形成，存证仅为证明创作先后顺序，而非授予版权。请确保角色与既有知名角色具有足够区分度，避免使用任何既有角色名称、作品名或标志性设定。
